# CarpetFall Roadmap — версия для GitHub Pages

Доска задач одним файлом. Кладётся в репозиторий, открывается по ссылке,
содержимое зашифровано кодовой фразой команды.

**В репозитории:** `index.html` — вся доска. `data.json` появится сам, когда
вы первый раз сохраните — это зашифрованное содержимое доски.

---

## Шаг 1. Создать репозиторий

1. Зайдите на <https://github.com>, войдите или зарегистрируйтесь.
2. Справа вверху **+** → **New repository**.
3. Имя — например `carpetfall-board`. Тип — **Public** (на бесплатном тарифе
   Pages работают только из публичных репозиториев).
4. **Create repository**.

## Шаг 2. Залить файл

На странице репозитория: **Add file** → **Upload files** → перетащите
`index.html` → внизу **Commit changes**.

## Шаг 3. Включить Pages

**Settings** (вкладка вверху репозитория) → слева **Pages** →
*Source*: **Deploy from a branch** → *Branch*: **main**, папка **/ (root)** →
**Save**.

Через минуту-две наверху той же страницы появится адрес вида:

```
https://ВАШ-НИК.github.io/carpetfall-board/
```

Это и есть ссылка на доску.

## Шаг 4. Придумать кодовую фразу

Откройте адрес. Доска увидит, что файла с данными ещё нет, и предложит
придумать фразу. Придумайте — ею будет зашифровано всё содержимое.

Фразу раздайте команде (например, в закрытом канале Discord). **Без неё доску
не открыть**, даже скачав файл напрямую.

## Шаг 5. Токен, чтобы правки сохранялись

Пока без токена правки живут только в вашем браузере. Чтобы они попадали в
репозиторий и их видела команда:

1. Откройте <https://github.com/settings/personal-access-tokens>
2. **Generate new token** → тип **Fine-grained**.
3. *Repository access* → **Only select repositories** → выберите свой репозиторий.
4. *Permissions* → *Repository permissions* → **Contents: Read and write**.
5. **Generate token**, скопируйте строку (она показывается один раз).
6. На доске нажмите **⚙** → вставьте токен в поле → **Сохранить**.

Готово: теперь каждая правка сама уезжает в репозиторий. В шапке видно
состояние — «Сохранено», «Есть правки», «Сохранение».

## Кому что нужно

| | что нужно |
|---|---|
| **Смотреть доску** | ссылка + кодовая фраза |
| **Править доску** | ещё и свой токен + доступ к репозиторию |

Чтобы кто-то из команды мог править, добавьте его в репозиторий:
**Settings** → **Collaborators** → *Add people*. После этого он создаёт себе
токен по шагу 5 и вставляет его в своих ⚙ Настройках. Токен у каждого свой,
делиться им нельзя.

---

## Как это защищено

В репозитории лежит только шифртекст (AES-256-GCM, ключ из фразы через
PBKDF2-SHA256, 250 000 итераций). Фраза набирается в браузере, никуда не
отправляется и нигде не хранится. Кто угодно может скачать `data.json` —
и не прочитает ничего без фразы.

Из этого следуют две вещи:

- **Фраза — это вся защита.** Не публикуйте её там, где её увидят посторонние.
  Утекла — смените: ⚙ → *Кодовая фраза* → **Сменить**, и раздайте новую.
- **Забыли фразу — данные не вернуть.** Восстановления нет, это не «сброс
  пароля», а именно шифрование.

Токен — отдельная история: он даёт запись в репозиторий. Тоже никому не
показывайте; если засветился — удалите его на странице токенов GitHub.

## Мелочи, которые пригодятся

- **Обновить** в шапке — подтянуть правки, которые сделали другие. Сама доска
  проверяет обновления раз в три минуты.
- Если двое правили одновременно, доска покажет «В репозитории есть версия
  новее» и спросит, что оставить.
- **Ctrl+S** — сохранить сразу, не дожидаясь автосохранения.
- ⚙ → **Скачать data.json** — запасной путь без токена: скачать файл и
  загрузить его в репозиторий вручную (*Add file → Upload files*).
- Доска работает только по `https://` (то есть по адресу Pages) или через
  `localhost`. Открытый двойным кликом файл с диска браузер считает
  небезопасным и отключает шифрование.
- Владелец, репозиторий и ветка определяются по адресу страницы сами. Если у
  вас свой домен — впишите их вручную в ⚙ Настройках.

## Если что-то не так

| симптом | что делать |
|---|---|
| «Фраза не подошла» | проверьте раскладку и Caps Lock; фраза чувствительна к регистру |
| «Токен не подошёл» | у токена нет права *Contents: Read and write* или он не привязан к этому репозиторию |
| правки не видны у команды | они не нажали **Обновить**, либо у вас в шапке висит «Не сохранено» |
| страница не открывается | Pages ещё разворачивается (первый раз до пары минут) либо в *Settings → Pages* не выбрана ветка |
| «Шифрование недоступно» | страница открыта как файл с диска — откройте по адресу Pages |
